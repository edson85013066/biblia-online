# Texto bíblico — Almeida 1911

O projeto utiliza a edição **Almeida 1911**, de João Ferreira de Almeida, para a leitura bíblica.

A documentação utilizada pelo projeto trata o texto da edição de 1911 como domínio público. Antes de redistribuir o conteúdo em outro produto, é recomendável conferir a situação jurídica específica da edição e da fonte utilizada.

Fonte de distribuição técnica usada no build:
- `barretogustavo/smart-bible-versions`
- arquivo: `ALM1911 - Almeida 1911.json`

O projeto não altera intencionalmente o texto bíblico baixado. O arquivo é incorporado automaticamente durante o build em `assets/data/almeida-1911.json`.

**Observação:** esta informação documenta a origem e a base jurídica considerada pelo projeto; qualquer conteúdo adicional, revisão ortográfica, comentário, estudo, imagem ou tradução futura deve ter sua própria verificação de licença.
